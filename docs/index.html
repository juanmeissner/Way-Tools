Política de Privacidade

Esta política explica como a extensão Way Tools trata informações durante o uso de suas ferramentas nos sistemas compatíveis.

Última atualização: 30 de setembro de 2026
Resumo: o Way Tools processa dados localmente no navegador para oferecer recursos de produtividade nos sistemas internos compatíveis. A extensão não envia dados de usuários para servidores controlados pelo desenvolvedor, não vende dados e não utiliza dados para publicidade, perfilamento ou análise de crédito.

Os campos destacados acima devem ser substituídos pelas informações reais antes da publicação desta política.

2. Escopo e finalidade

A finalidade do Way Tools é melhorar e padronizar a produtividade dos usuários nos fluxos de atendimento técnico e operacional. Para cumprir essa finalidade, a extensão oferece mensagens padronizadas, cópia de dados operacionais, alertas de inatividade, interface compacta, tema visual, apoio ao agendamento de visitas e correção ortográfica.

A extensão atua somente nos seguintes endereços:

  • https://ia-nocodb.internetway.com.br/*
  • https://erp.internetway.com.br/*
  • https://wayinternet.matrixdobrasil.ai/*

3. Dados tratados

Conforme o recurso utilizado e as informações exibidas nos sistemas compatíveis, a extensão pode tratar localmente as categorias abaixo.

Informações de identificação pessoal

Nome, CPF, telefone, e-mail, endereço, número de contrato, protocolo e outros identificadores exibidos durante o atendimento.

Comunicações pessoais

Textos digitados ou colados em campos de mensagens, conversas de atendimento e modelos de mensagens criados pelo usuário.

Localização

Endereços e endereços IP exibidos nos sistemas e utilizados pelas funções de cópia ou preenchimento de visitas técnicas.

Conteúdo dos sites compatíveis

Textos, campos, informações do atendimento, contadores de inatividade e elementos de interface necessários para executar as ferramentas oferecidas.

Dados de configuração

O Way Tools também armazena preferências técnicas, como ferramentas ativadas, mensagens personalizadas, limites de alertas, preferência de tema, posição de abas e estado do corretor ortográfico.

A extensão não trata intencionalmente informações de saúde, dados financeiros ou de pagamento, credenciais de autenticação ou histórico geral de navegação.

4. Como os dados são utilizados

Os dados são utilizados exclusivamente para as funcionalidades visíveis ao usuário:

  • preencher e personalizar mensagens de atendimento;
  • corrigir ortografia e padronizar termos técnicos;
  • copiar dados operacionais mediante ação do usuário;
  • preencher e manter temporariamente rascunhos de visitas técnicas;
  • calcular e apresentar alertas de inatividade;
  • adaptar a interface e o tema dos sistemas compatíveis;
  • salvar preferências e configurações escolhidas pelo usuário.

Os dados não são utilizados para publicidade, perfilamento, análise de crédito, monitoramento comportamental ou qualquer finalidade não relacionada às funções declaradas.

5. Armazenamento e retenção

  • Armazenamento da extensão: preferências, mensagens e configurações são mantidas localmente pelo chrome.storage.local no perfil do navegador.
  • Rascunhos temporários: dados de visitas técnicas podem ser mantidos no sessionStorage, separados por atendimento, e normalmente são descartados ao encerrar a aba ou sessão correspondente.
  • Área de transferência: informações somente são copiadas quando o usuário aciona uma função de cópia. A retenção posterior é controlada pelo sistema operacional e pelo próprio usuário.

As configurações locais permanecem até serem alteradas ou removidas pelo usuário, pela limpeza dos dados da extensão ou pela desinstalação do Way Tools.

6. Compartilhamento e transmissão

O Way Tools não envia dados para servidores controlados pelo desenvolvedor e não vende, aluga ou compartilha dados com anunciantes ou terceiros. A extensão não contém ferramentas de analytics, publicidade ou rastreamento.

As interações realizadas diretamente nos sistemas compatíveis continuam sujeitas às regras e políticas desses próprios sistemas. O Way Tools apenas auxilia a interface local exibida no navegador.

7. Permissões utilizadas

storage

Usada para salvar localmente configurações, preferências e mensagens da extensão.

Permissões dos hosts compatíveis

Usadas para executar os recursos somente no IA NocoDB, ERP Way e Matrix, permitindo que a extensão leia e ajuste os elementos necessários dessas páginas. Não é solicitado acesso a todos os sites visitados pelo usuário.

A extensão não baixa nem executa código remoto.

8. Controle do usuário

O usuário pode:

  • ativar ou desativar individualmente as ferramentas pelo painel do Way Tools;
  • alterar ou excluir mensagens personalizadas;
  • apagar rascunhos temporários ou encerrar a aba correspondente;
  • remover os dados locais ao desinstalar a extensão ou limpar seus dados no Chrome.

9. Uso limitado dos dados

O uso dos dados pelo Way Tools é limitado ao fornecimento e à melhoria das funcionalidades visíveis descritas nesta política. Os dados não são transferidos para publicidade personalizada, não são vendidos, não são utilizados para determinar capacidade de crédito e não são disponibilizados para leitura humana pelo desenvolvedor.

O tratamento é proporcional às funções solicitadas pelo usuário e restrito ao mínimo necessário para o funcionamento da extensão.

10. Segurança

A extensão foi projetada para processar os dados no próprio navegador e limitar sua atuação aos domínios declarados. Nenhum método de armazenamento ou processamento é totalmente livre de riscos; por isso, os usuários devem proteger o perfil do navegador, o dispositivo e o acesso aos sistemas corporativos.

11. Uso por menores

O Way Tools é destinado a atividades profissionais em sistemas internos e não é direcionado a crianças ou adolescentes.

12. Alterações desta política

Esta política poderá ser atualizada quando houver mudanças relevantes na extensão ou nas exigências aplicáveis. A data de atualização será indicada no início da página. Alterações materiais nas práticas de dados serão comunicadas de forma compatível com os requisitos da Chrome Web Store.
