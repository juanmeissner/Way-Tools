# Imagens das mensagens automáticas

Coloque nesta pasta os arquivos de imagem usados pelos comandos de mensagens do Way Tools.

O comando `!enviarimagem`, disponível nos perfis N2 e SAC, usa exatamente:

`enviarimagem.png`

Caminho completo dentro do projeto:

`Way Tools/assets/mensagens/enviarimagem.png`

O nome e a extensão devem permanecer em letras minúsculas. O arquivo será anexado ao compositor do ChatWoot ou do Matrix para conferência antes do envio ao cliente.
